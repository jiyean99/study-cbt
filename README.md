## 무엇이 되나요

- **과목 검색** — 허브에서 과목명이나 SQL · 파이썬 · 통계 같은 키워드로 바로 찾기 (`/` 키로 검색창 이동)
- **실제 시험과 같은 응시 환경** — 타이머와 자동 제출, 답안지(OMR), 보류 표시, 보기 순서 섞기
- **과목별 채점** — 총점과 과목별 성취도를 커트라인과 함께 막대로 표시하고, 틀린 문항만 모아 보기
- **입력형 채점** — 실기 과목은 답을 직접 입력하며, 대소문자·공백·따옴표 차이는 정답 처리
- **문항별 배점** — 빅분기 실기·SQLP처럼 문항마다 배점이 다른 시험도 그대로 반영 (예: SQLP 객관식 1점 / 서술형 15점)
- **두 가지 과락 기준** — 정답 문항 수 기준(`cut`)과 점수 기준(`cutScore`)을 모두 지원
- **학습 기록** — 채점 결과가 브라우저에 저장되어 허브 카드에 최근·최고 점수로 표시되고, 과목별 시험일 D-day를 설정할 수 있음

기록은 `localStorage`에만 저장되며 서버로 전송되지 않습니다.

## 실행

```bash
python -m http.server 5599
```

브라우저에서 `http://localhost:5599` 를 엽니다. GitHub Pages에 그대로 올려도 동작합니다.

## 구조

```
├── index.html              학습 허브 (루트) — 검색, 과목 카드, 진행 상황, D-day
├── assets/
│   ├── design.css          디자인 시스템 (색·타이포·버튼·카드 토큰, 다크 모드 포함)
│   ├── exam.css            시험 화면 (표지 / 응시 / 채점 결과)
│   ├── exam-engine.js      공용 CBT 엔진 — 객관식·단답형·약술형 채점
│   └── study-hub.js        학습 기록 저장소 (localStorage)
├── network/  sqld/  sqlp/  bigdata/  bigdata-practical/
├── sitpe/  linux2/  aws-aif/
│   ├── index.html          EXAM_META (시험 규격·합격 기준·반영 회차)만 정의
│   └── data.js             문항 데이터
```

모든 페이지가 `assets/`의 디자인 시스템과 엔진 하나를 공유합니다.
과목 페이지는 **시험 규격과 문항 데이터만** 정의하고, 화면과 채점은 엔진이 처리합니다.

## 과목 추가하기

1. 폴더를 만들고 `data.js`에 `window.EXAMS = [{ title, note, q: [...] }]` 를 정의합니다.
2. `index.html`에 `window.EXAM_META`(문항 수, 시간, 배점, 과목 구성, 합격 기준, 반영 회차)를 쓰고
   `design.css` · `exam.css` · `study-hub.js` · `data.js` · `exam-engine.js` 를 순서대로 불러옵니다.
3. 루트 `index.html`의 `CERTS` 배열에 카드 한 줄을 추가합니다.

### 문항 형식

```js
// 객관식 (t 생략 가능)
{ n: 1, s: 1, q: "문제", code: "코드(선택)", o: ["보기1","보기2","보기3","보기4"], a: 2, e: "해설" }

// 단답형 — 빈칸이 여러 개면 모두 맞아야 득점
{ n: 1, s: 1, t: 'short', q: "문제", code: "코드(선택)",
  blanks: [{ lbl: "출력", accept: ["정답", "허용 표기"] }], e: "해설" }

// pts를 주면 그 문항만 배점이 달라집니다 (없으면 EXAM_META.perQuestion)
{ n: 4, s: 2, t: 'desc', pts: 40, q: "문제", model: "모범답안" }

// 과목 과락은 문항 수(cut) 또는 점수(cutScore) 중 하나로 지정합니다
// subjects: [{ name, short, count, cut: 8 }]  또는  [{ ..., cutScore: 28 }]

// 약술형 — 채점 후 모범답안을 보고 스스로 표시
{ n: 20, s: 2, t: 'desc', q: "문제", model: "모범답안", points: ["채점 포인트"], e: "해설" }
```

## 문항 출처와 주의

- 네트워크관리사 2급은 기출 복원 문항을 ICQA 출제기준(과목당 5~18문항, 총 50문항)에 맞춰 4과목 체계로 재분류하고 최근 반복 출제 영역을 보강한 것입니다.
- 정보처리기사 실기는 '정처기 감자' 실기 압축 요약 PDF(이론·코딩 ver 2-2, 2026.7.17 배포)의 예상 출제 범위와 비중을 따랐으며, C·Python 문항은 실제 컴파일·실행으로 정답을 검증했습니다.
- 빅데이터분석기사 실기는 기출문제와 시험 데이터셋이 공식 비공개입니다. 제6회부터 고정된 출제 체계(작업형1 3문항 / 작업형2 1문항 / 작업형3 2세트)와 최근 회차에서 반복된 유형을 반영해 재구성했으며, 작업형1·3의 수치 정답은 전부 직접 계산해 검증했습니다(t·카이제곱·F 분포 함수는 표준 임계값과 일치 확인).
- SQLP는 SQL 전문가 가이드의 출제 범위를 기준으로 새로 작성했습니다. 과목별 문항 수와 배점(객관식 70×1점 + 서술형 2×15점), 총점 75점·과목별 40% 과락은 실제 시험 규격 그대로입니다.
- 리눅스마스터 2급은 KAIT가 공개한 2급 출제기준의 대분류(리눅스 일반 / 리눅스 활용)를 따랐고, 과목별 문항 수는 실제 출제 비중에 맞춰 배분했습니다.
- AWS AI Practitioner는 시험 문제가 비공개이고 덤프 사용이 인증 정책 위반이므로, 공식 시험 가이드의 도메인별 과제 명세를 기준으로 새로 작성했습니다. 도메인 문항 수는 공식 가중치(20/24/28/14/14%)에 정확히 맞췄습니다.
- 어느 과목도 특정 회차의 기출을 그대로 옮긴 것이 아닌 **출제 범위·경향 기반의 모의고사**입니다. 최신 회차를 반영할 때는 각 페이지의 `EXAM_META.coverage`와 루트 `index.html`의 `CERTS[].coverage`를 함께 갱신해 주세요.
